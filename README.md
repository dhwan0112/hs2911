# HS2911 — Social Media and Mental Health

Course materials for HS2911 (NUS, 2026), organised from the course file export.

## Layout

| Folder | Contents |
|---|---|
| `lectures/` | Weekly lecture slides (Week 01–12). `week-07-activity/` holds the Week 7 in-class debate materials (orientation/debrief slides, podcast audio, transcript, discussion task). |
| `readings/` | Weekly readings, one folder per week (`week-01` … `week-12`) plus `tutorial-02`, `tutorial-03`. File prefixes: `RR` = required reading, `SR`/`S` = supplementary, `Compulsory_` = marked compulsory in Week 10. |
| `quizzes/` | Practice quizzes for Weeks 7–12 (Word), the question-type guide, and the instructor note on the final quiz. |
| `project/` | Group project cover page template, a demo final presentation, and the instructor's feedback on demo decks (`Demo_decks_feedback.md`). |
| `misc/` | Other items from the export (participant recruitment poster). |

## Notes

- Seven supplementary PDFs appeared both in `Week 9/Supplementary Readings` and `Week 10` in the original export. They are kept once, under `readings/week-09/supplementary/`.
- File names were normalised (spaces → underscores, `.pdf_safe.pdf` → `.pdf`, missing extensions added). Content is unchanged.
- Two slide decks over 50 MB (`Week_04_…`, `Week_07_…`) are stored with Git LFS. Run `git lfs install` before cloning to get the actual files.

## Final quiz (from the instructor note)

- Pen-and-paper, closed book; covers Weeks 7–12 including Tutorial 3.
- Only material discussed in class / on lecture slides / tutorial handouts.
- About 25–30 questions, roughly two minutes each.
