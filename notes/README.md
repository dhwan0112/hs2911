## Quiz walkthroughs

`quiz-walkthrough/week-NN.md` goes through every practice-quiz question: condensed stem, the correct
letter, why it is right (with slide refs), why each other option is wrong, and the distractor pattern
("trap"). Use them after attempting the quiz in `quizzes/` closed-book.

## Question types (from `quizzes/HS2911-quizquestiontypes.docx`)

A Conceptual understanding · B Analysis · C Application · D Evaluation · E Integration · F Creation.
The practice quizzes are ordered A→F and get harder within each block; expect the same on the final.

## Suggested order

1. Read the week note (15 min), then attempt the practice quiz closed-book, timed at 2 min/question.
2. Mark it with the answer key in the quiz file, then read the walkthrough for every miss *and* every
   guess, focusing on the "Trap" line.
3. Re-read the "Distractor traps" and "60-second recap" sections of all seven notes the day before.
